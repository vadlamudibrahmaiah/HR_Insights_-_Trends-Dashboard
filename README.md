Project Title: HR Insights & Trends Dashboard

Description:
The HR Insights & Trends Dashboard is a data visualization project created using Power BI to help HR teams monitor and analyze employee data. The dashboard converts raw HR data into meaningful insights using charts, KPIs, and trend analysis.

Dataset Includes:

Employee details

Department information

Salary data

Employee performance

Attendance and attrition data

Tools Used:

Power BI

Microsoft Excel

Power Query

Features:

Employee performance analysis

Department-wise workforce insights

Attrition trend analysis

Interactive charts and filters for better data exploration

Outcome:
This dashboard helps HR teams easily understand workforce trends and make data-driven decisions to improve employee management and organizational performance.
